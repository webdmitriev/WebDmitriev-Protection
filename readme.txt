Легковесный модуль безопасности, защиты от атак и мониторинга целостности файлов.

== Description ==

WebDmitriev Protection — комплексное компактное решение для защиты сайта на WordPress:
* Защита от подбора паролей (Limit Login Attempts).
* Занятие защитных позиций для xmlrpc.php и скрытие пользователей в REST API.
* Мониторинг изменений .htaccess и wp-config.php.
* Автоматическая защита папки Uploads от запуска PHP.
* Легковесный WAF: блокировка атак по URL, фильтрация вредоносных User-Agent и черный список IP.

== Installation ==

1. Загрузите папку плагина в директорию `/wp-content/plugins/`.
2. Активируйте плагин через меню 'Плагины' в WordPress.
3. Перейдите в раздел 'WD Protection' для настройки.
