# Web Dmitriev protection wordpress

---

### Возможности

1. Защита точек входа (Анти-Брутфорс и Боты)
Готово: Полностью заблокирован xmlrpc.php, включен лимит попыток входа (5 попыток с баном IP на 15 минут) в modules/auth-security.php, закрыты ?author=1 и публичный эндпоинт REST API /wp/v2/users.

2. Мониторинг и Защита Файловой Системы
Готово: В modules/file-guard.php реализован автоматический запрет исполнения PHP в /uploads/ через .htaccess, отслеживание изменений хэшей критических файлов (wp-config.php, root .htaccess) с возможностью переутверждения из админки, а также сканирование /uploads/ на сторонние PHP-файлы.

3. IP-Фильтрация и Логирование (Firewall)
Готово: Кастомная таблица в БД (wp_wd_protection_logs), запись угроз с уровнями критичности, ручной бан IP через текстовое поле в админке с проверкой на каждом запросе в modules/firewall.php.

4. Валидация и Очистка Данных (Sanitization & Headers)
Готово: Авто-подстановка заголовков безопасности (X-Frame-Options, X-Content-Type-Options, X-XSS-Protection, Referrer-Policy), блокировка известных сканеров по User-Agent (sqlmap, nikto и др.) и фильтрация GET-параметров URL на базовые SQLi / XSS / Path Traversal.

5. Автоматика и Оповещения
Готово: В фоновом режиме работает ежедневный крон wd_daily_file_integrity_check для сканирования целостности файлов и поиска PHP в uploads. Вывод уведомлений в админ-панели WP при обнаружении угроз.
